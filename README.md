# School-Trajectories
Dieses Dashboard basiert auf der Masterarbeit des Autors über schulische Werdegänge von „Bolsa Família“-Begünstigten (brasilianisches Sozialprogramm) in Amparo (PUC-Campinas, 2022). Es umfasst 6 reale Datensätze aus Feldforschungsinterviews sowie 26 synthetische Datensätze ohne Personenbezug, die für dieses Power-BI-Portfolio erstellt wurden.
